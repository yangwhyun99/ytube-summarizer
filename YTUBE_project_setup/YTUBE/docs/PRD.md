# PRD: YouTube Video Summarizer (YTSummarizer)

## 1. 프로젝트 개요

### 1.1 비전
YouTube 영상을 음성(트랜스크립트) + 영상(키프레임 캡처)을 종합 분석하여 핵심 내용을 빠짐없이 정리하고, 같은 주제의 영상들을 누적 요약하여 **개인 지식 베이스**로 발전시키는 웹 애플리케이션.

### 1.2 대상 콘텐츠
- 경제학 강의
- AI 활용 팁 영상
- 코딩 튜토리얼 (예: Claude Code, Playwright MCP 등)
- 기타 교육/정보성 콘텐츠

### 1.3 대상 사용자
- 영상을 통해 학습하는 개인 사용자
- 다수의 영상을 체계적으로 정리하고 싶은 학습자

## 2. 핵심 기술 아키텍처

### 2.1 요약 파이프라인

```
YouTube URL 입력
    ├─→ 트랜스크립트 추출 (youtube-transcript-api / yt-dlp + Whisper)
    ├─→ 영상 다운로드 → ffmpeg scene detection 키프레임 추출
    └─→ AI 엔진에 텍스트 + 이미지(30~50장) 함께 전송
         ├─ 기본: Gemini 2.5 Flash (무료)
         └─ 프리미엄: Claude Sonnet (유료, 선택 가능)
            ↓
        종합 요약 생성 (타임스탬프 포함)
            ↓
        웹에 저장 + PDF/DOCX 내보내기 가능
```

### 2.2 Scene Detection 방식 (고정 간격 X)
- `ffmpeg -vf "select='gt(scene,0.3)'" -vsync vfr` 사용
- 장면 변화 시점에만 캡처 → 3초 이하 팝업도 감지
- 최소 10초 간격 보장 캡처 병행 (변화 없는 구간 보완)
- 중복/유사 프레임 자동 제거
- 20분 영상 기준: 약 30~50장 추출

### 2.3 AI 분석 전략
- 트랜스크립트: 발화 내용 전체 맥락 파악
- 키프레임: 슬라이드 텍스트, 코드, 차트, UI 화면 인식 (별도 OCR 불필요, Gemini/Claude 비전으로 충분)
- 두 소스를 종합하여 요약 생성
- 시각 자료가 없는 토크 위주 영상: AI가 인포그래픽/개념도 생성 (선택적)

### 2.4 AI 엔진 전략 (듀얼 엔진)
- **기본 엔진: Gemini 2.5 Flash** — 무료, 하루 250건, 멀티모달 지원, 100만 토큰 컨텍스트
- **프리미엄 엔진: Claude Sonnet** — 유료($0.2~0.3/영상), 더 정교한 요약
- 두 엔진은 동일한 인터페이스(ABC)로 추상화하여 교체 용이하게 설계
- 사용자가 설정에서 엔진 선택 가능

## 3. 기능 명세

### 3.1 MVP (1차 출시)

| 기능 | 상세 |
|------|------|
| YouTube URL 입력 | 단일 URL 붙여넣기 → 즉시 요약 시작 |
| 종합 요약 생성 | 트랜스크립트 + 키프레임 기반, 핵심 빠짐없이 정리 |
| 다국어 지원 | 한국어/영어 영상 모두 분석 가능 |
| 요약 상세도 조절 | "핵심만 1분 요약" vs "강의 노트 수준 상세 요약" 선택 |
| 요약 언어 선택 | 영어 영상 → 한국어 요약 / 영어 요약 선택 |
| PDF/DOCX 내보내기 | 요약 결과를 파일로 다운로드 |
| 웹 영구 저장 | 삭제하지 않는 한 계속 보관 |
| 모바일/웹 반응형 | 모바일에서도 완전한 사용 가능 |

## 4. 지식 병합 (Knowledge Merge) 기능 상세

### 4.1 개요
같은 주제의 영상 요약본들을 누적 병합하여 하나의 "최신화된 종합본"을 만들어나가는 기능.

### 4.2 병합 로직
```
새 영상 요약 생성
    ↓
기존 종합본의 목차(섹션 리스트)와 비교
    ↓
AI가 관련 섹션 판별 (가벼운 호출, ~500 토큰)
    ↓
해당 섹션만 가져와서 병합:
  - 중복 내용 → 삭제
  - 기존 내용 보완 → 업데이트
  - 새로운 내용 → 신규 섹션 추가
    ↓
변경 diff 리뷰 → 사용자 승인/수정
    ↓
종합본 업데이트 완료
```

### 4.3 설계 원칙
- 종합본은 **섹션별 분리 관리** (전체를 한 번에 처리하지 않음)
- 영상 50개 이상 누적되어도 매번 처리하는 토큰은 일정하게 유지
- 추가 비용: 영상당 약 $0.02~0.05 (30~70원)

### 4.4 사용 시나리오
> 사용자가 "Claude Code" 관련 영상 10개를 차례로 요약함
> → 시스템이 자동으로 "Claude Code 종합 가이드" 문서를 만들어감
> → 중복은 제거, 새로운 팁은 추가, 버전 업데이트 내용은 최신화

## 5. 비용 및 성능 예상

### 5.1 영상 1개 요약 (15~20분 기준)

**Gemini 2.5 Flash (기본, 무료)**

| 항목 | 수치 |
|------|------|
| 일일 요청 한도 | 250건/일 (영상 요약 충분) |
| 분당 토큰 한도 | 250,000 TPM |
| 컨텍스트 윈도우 | 1,000,000 토큰 |
| **비용** | **$0 (무료)** |

**Claude Sonnet (프리미엄, 유료)**

| 항목 | 토큰 | 비용 |
|------|------|------|
| 트랜스크립트 (입력) | 2,000~4,000 | - |
| 키프레임 40장 (입력) | 40,000~65,000 | - |
| 요약 출력 | 2,000~4,000 | - |
| **합계** | **~70,000** | **$0.2~0.3 (300~400원)** |

**지식 병합 추가 비용 (어떤 엔진이든)**

| 엔진 | 비용 |
|------|------|
| Gemini Flash | $0 (무료 한도 내) |
| Claude Sonnet | $0.02~0.05 (30~70원) |

### 5.2 처리 시간

| 단계 | 소요 시간 |
|------|----------|
| 트랜스크립트 추출 | 2~5초 |
| 영상 다운로드 + ffmpeg scene detection | 30초~2분 |
| AI API 호출 (텍스트+이미지) | 15~40초 |
| **총합** | **약 1~3분** |

### 5.3 무료 운영 가능 범위
- Gemini Flash 기본 사용 시 하루 최대 약 100~125개 영상 요약 가능 (영상당 2회 호출 가정)
- 개인 사용 목적이면 무료로 충분
- 이미지 수를 30~50장 선에서 조절하는 것이 핵심

## 6. 기술 스택 (확정 예정)

### 6.1 Frontend
- **Next.js** (App Router)
- **TypeScript** (strict mode)
- **Tailwind CSS**
- 모바일 반응형 설계

### 6.2 Backend
- **Python (FastAPI)** - 영상 처리 파이프라인
  - yt-dlp: 영상 다운로드
  - ffmpeg: scene detection + 키프레임 추출
  - youtube-transcript-api: 자막 추출
  - Whisper (fallback): 자막 없는 영상용 STT
- **AI 엔진 (듀얼)**
  - 기본: **Google Gemini 2.5 Flash** (google-genai SDK, 무료)
  - 프리미엄: **Claude Sonnet** (anthropic SDK, 유료)
  - 추상화 인터페이스로 엔진 교체 용이

### 6.3 Storage & DB
- 확정 예정 (Supabase / PostgreSQL / Firebase 등)
- 파일 스토리지: 키프레임 이미지 + PDF/DOCX 내보내기 파일

### 6.4 배포
- 확정 예정 (Vercel + Railway / AWS 등)

## 8. 성공 기준

1. 15~20분 영상을 3분 이내에 요약 완료
2. 요약에서 영상의 핵심 내용이 90% 이상 포함
3. 코딩 튜토리얼의 코드/명령어가 정확히 캡처됨
4. 지식 병합 시 중복 없이 체계적으로 정리됨
5. 모바일에서 불편 없이 사용 가능
